# Final-4 — محاكاة الصفقات المعاكسة

بوت الانعكاس الذي نُقل من Final-3 إلى هذا المستودع المستقل. ملف التشغيل `cascade_final4_paper.py` والصنف `Final4PaperHunter`. هذه النسخة المعتمدة تستخدم وقف2.8% ومعاكسة45% وتخفيف الأصلية مع وقف من السعر الحالي؛ نسخة الوقف والإغلاق الجزئي المتدرج تبقى في [Final-3](https://github.com/khaledhasneen1993/Final-3).

## الإعدادات المعتمدة

| الإعداد | القيمة |
| --- | --- |

| الرافعة الحسابية | 50× |
| الوقف الأولي لكل مركز | 2.8% من سعر تنفيذه |
| انعكاس الأصلية لتجهيز المعاكسة | 1.8% مع إشارة معاكسة |
| حجم المعاكسة | 45% من القيمة الاسمية لدخول الأصلية |

| حد الخسارة المجمعة | معطّل حاليًا؛ لا إغلاق جماعي عند2.2% أو8% من الرصيد |
| مهلة إعادة المعاكسة للعملة | أكثر من600ثانية بعد إغلاق مركز نشأ كمعاكسة |

شروط الإشارة: حركة تتجاوز ±1.2%، وحجم أكبر من3.5أضعاف المتوسط، واختلال دفتر أوامر يتجاوز ±0.35. لا يوجد تعزيز. الإغلاق الجزئي هنا مرتبط بنجاح فتح المعاكسة، وليس بمراحل Final-3.

## التعامل مع المعاكسة

لكل مركز `position_id` مستقل، مع بقاء `symbol` رمز السوق الحقيقي لجلب البيانات. الأصلية والمعاكسة لها كميات وهامش ووقف وربح وسجل مستقل، ويمكنهما البقاء مفتوحتين في الوقت نفسه.

- تُفتح المعاكسة عند انعكاس1.8% مع إشارة في الاتجاه المعاكس، بشرط كفاية الهامش والرسوم وحقوق الحساب وعدم اكتمال حد5مراكز.
- يُحسب الحجم من سعر التنفيذ الفعلي مع التقريب وفق السوق. يُعاد فحص عتبة الانعكاس ووقف الأصلية قبل التعبئة؛ ارتداد السعر يلغي محاولة الانعكاس، وتجاوز الوقف يمنعها ويؤدي لمحاولة تسوية الأصلية.
- بعد نجاح فتح المعاكسة تُرسل محاولة إغلاق50% من الأصلية بسبب `REVERSAL_HEDGE`، ثم يُشد وقف المتبقي بالمعادلة `price × (1 − direction × 0.007)`. لا يُبعد وقف سابق أقرب. إذا فشل الإغلاق الجزئي يُسجّل الخطأ، وتبقى الكمية الفعلية تحت الوقف الجديد؛ لا تُفتح معاكسة مكررة ولا تُعاد محاولة التخفيف تلقائيًا.
- عند ربح المعاكسة0.7% تُغلق بقية الأصلية بسبب `REVERSAL_WIN` وتبقى المعاكسة كمركز رئيسي بمعرّفها ووقفها. إغلاق الأصلية بسبب آخر يرقّي المعاكسة أيضًا.
- بعد إغلاق المعاكسة بنجاح يُحفظ وقت الإغلاق للعملة، وتُمنع معاكسة جديدة عليها حتى مرور أكثر من600ثانية، بما في ذلك بعد إعادة التشغيل وبعد ترقية المعاكسة إلى مركز رئيسي. إغلاق الأصلية وحدها لا يبدأ هذه المهلة.
- إذا توقفت المعاكسة وحدها، تبقى الأصلية تحت وقفها ولا تُفتح معاكسة ثانية للأصلية نفسها.
- لا يُسمح بدخول عادي جديد على العملة ما دام أي مركز عليها مفتوحًا، حتى لو بقيت المعاكسة المرقّاة فقط.

### أولوية الوقف ومثال التنفيذ

شراء عند100 ثم فتح معاكسة عند98.2: يُغلق نصف الأصلية ويصبح وقف الباقي المرشح97.5126، وليس98.8. للبيع عند100 ومعاكسة عند101.8، يصبح المرشح102.5126. هذه الأمثلة تفترض عدم تغير السعر بين فحص الشرط والتنفيذ؛ قد يختلف سعر التنفيذ الفعلي، والتقريب يتبع السوق.

لأن مسافة الوقف وتأكيد المعاكسة كلاهما0.7%، قد يتحققان في الفحص نفسه. عند إدارة الأصلية أولًا يُسجّل خروجها `TIGHT_AFTER_REV`، ثم تُرقّى المعاكسة وتبقى مفتوحة؛ وقد يظهر `REVERSAL_WIN` إذا عولج تأكيدها أولًا. لا يتكرر إغلاق الأصلية. الوقف له الأولوية، بما فيه عند تجاوز السعر وقف2.8% قبل إمكان فتح معاكسة.

حد الخسارة المجمعة معطّل عمدًا حتى لا يسبق عتبة المعاكسة: دخول بهامش10% ورافعة50× يخسر قرابة9% من الرصيد عند حركة سعرية عكسية1.8% قبل الرسوم. لا يوجد الآن سقف خسارة جماعي للحساب؛ تبقى وقفات المراكز وقفل الربح والتخفيف ومهلة المعاكسة فعالة.

نجاح المعاكسة لا يعني أن صافي المركزين معًا أصبح موجبًا. التنفيذ بسعر السوق المرصود، ولا يضمن سعر الوقف نفسه.

## التشغيل داخل Ubuntu في Termux

يتطلب Python3.11+ وGit وvenv:

```bash
cd /root
git clone https://github.com/khaledhasneen1993/Final-4.git
cd Final-4
bash run_paper.sh
```

السكربت يجهّز `.venv` ويثبت المكتبات. ملف الحالة الافتراضي `paper_state_final4.json`، مستقل عن Final-3. Ctrl+C يحفظ المراكز ولا يغلقها؛ تتوقف مراقبتها حتى الاستئناف.

لحساب جديد منفصل:

```bash
bash run_paper.sh --state sessions/final4-new.json
```

لتحديث نسخة موجودة، أوقفها بـCtrl+C أولًا ثم:

```bash
cd /root/Final-4
git pull --ff-only
bash run_paper.sh
```

استخدم مسار `--state` نفسه إذا كان حسابك مخصصًا. التحديث لا يغيّر عملية تعمل مسبقًا، ولا يعيد الحساب إلى100. لا تستخدم `--reset` للاستئناف.

## استئناف حساب الانعكاس السابق

ملفات الحساب الموجودة على هاتفك لا تنتقل تلقائيًا بمجرد نقل الكود على GitHub. بعد إيقاف جميع العمليات التي تستخدم الملف السابق، يمكن استئنافه بمساره الصريح، مثل:

```bash
bash run_paper.sh --state /root/Final-3/paper_state_final3_reversal.json
```

هذا المثال مناسب فقط إذا كان الملف هو فعلًا حساب نسخة الانعكاس. يمكن أن يكون حسابك تحت مسار جلسة مختلف؛ استخدم المسار الفعلي المحفوظ لديك. تُؤخذ نسخة احتياطية قبل ترقية إعدادات الحساب المعروفة. تُحفظ المراكز الأصلية والمعاكسة وروابطها والكميات والرصيد والتنفيذات. يُشد الوقف الأولي إلى2.8% دون إبعاد أي وقف سابق أقرب. المراكز المعاكسة القديمة لا يتغير حجمها بأثر رجعي، ولا يُنفذ تخفيف50% لمعاكسات فُتحت قبل التحديث؛ قواعد45% والتخفيف ووقف0.7% تُطبّق عند فتح معاكسة جديدة. تبدأ ذاكرة المهلة فارغة للحالات القديمة التي لا تحتويها، ثم تُحفظ بعد الإغلاق التالي. لا تُحوَّل حسابات نظام الوقف المتدرج إلى انعكاس تلقائيًا. ولا يُعاد الرصيد إلى100 عند الاستئناف.

```bash

```

تغطي الاختبارات المركزين المتعاكسين والهامش والرسوم وقفل1% وإغلاق الأصلية وحدها عند النجاح واستعادة الحالة السابقة وفصل السجل واللوحة. تعتمد على بيانات وهمية، ولا تثبت نجاح اتصال جهازك بالبورصة أو أداء تداول حقيقيًا.

المحاكاة لا تحسب التصفية أو التمويل أو الانزلاق. تُرفض تيكرات التنفيذ دون توقيت أو خارج ±10ثوانٍ. شروط الإشارات الأصلية لم تتغير. نجحت48حالة لاختبارات البوت و12حالة لاختبارات اللوحة باستخدام بيانات وهمية.
