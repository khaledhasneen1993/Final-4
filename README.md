# Final-4 — محاكاة الصفقات المعاكسة

بوت الانعكاس الذي نُقل من Final-3 إلى هذا المستودع المستقل. ملف التشغيل `cascade_final4_paper.py` والصنف `Final4PaperHunter`. حافظ النقل على شروط الإشارات ومنطق المخاطر؛ نسخة الوقف والإغلاق الجزئي المتدرج تبقى في [Final-3](https://github.com/khaledhasneen1993/Final-3).

## الإعدادات المعتمدة

| الإعداد | القيمة |
| --- | --- |
| رصيد حساب جديد | 100 USDT افتراضية |
| هامش الدخول العادي | 10% من الرصيد |
| الرافعة الحسابية | 50× |
| وقف كل مركز | 3% من سعر تنفيذه |
| انعكاس الأصلية لتجهيز المعاكسة | 1.8% مع إشارة معاكسة |
| حجم المعاكسة | 60% من القيمة الاسمية لدخول الأصلية |
| تأكيد نجاح المعاكسة | ربح سعري1.2%؛ يغلق الأصلية فقط |
| أقصى مراكز | 5، تشمل الأصلية والمعاكسة |
| قائمة العملات | أعلى40 عقد USDT-M مؤهل بحجم مقوّم لا يقل عن15مليون USDT |
| تحديث القائمة | كل600ثانية |
| البحث | مستمر عبر WebSocket |
| مراقبة الخروج | انتظار8ثوانٍ بين الدورات إضافةً لزمن الشبكة |

شروط الإشارة: حركة تتجاوز ±1.2%، وحجم أكبر من3.5أضعاف المتوسط، واختلال دفتر أوامر يتجاوز ±0.35. لا يوجد تعزيز أو إغلاق جزئي متدرج للخسارة في استراتيجية Final-4.

## قفل الربح

| الربح السعري المرصود | مستوى الوقف من الدخول |
| --- | --- |
| 1% | سعر الدخول،0% |
| 1.5% | +0.5% |
| 2% | +1% |
| 2.5% | +1.5% |
| 3% | +2% |
| 3.5% | +2.5% |
| 4% فأكثر | +3% |

تُطبّق المستويات للشراء والبيع والوقف لا يرجع لمستوى أضعف. مستوى0% تعادل سعري قبل الرسوم، وليس ضمانًا لصافي صفقة يساوي صفرًا. كل النسب تصف تغير السعر، لا تغير رصيد الحساب.

## التعامل مع المعاكسة

لكل مركز `position_id` مستقل، مع بقاء `symbol` رمز السوق الحقيقي لجلب البيانات. الأصلية والمعاكسة لها كميات وهامش ووقف وربح وسجل مستقل، ويمكنهما البقاء مفتوحتين في الوقت نفسه.

- تُفتح المعاكسة عند انعكاس1.8% مع إشارة في الاتجاه المعاكس، بشرط كفاية الهامش والرسوم وحقوق الحساب وعدم اكتمال حد5مراكز.
- يُحسب الحجم من سعر التنفيذ الفعلي مع التقريب وفق السوق. يُعاد فحص عتبة الانعكاس ووقف الأصلية قبل التعبئة؛ ارتداد السعر يلغي محاولة الانعكاس، وتجاوز الوقف يمنعها ويؤدي لمحاولة تسوية الأصلية.
- عند ربح المعاكسة1.2% تُغلق الأصلية بسبب `REVERSAL_WIN` وتبقى المعاكسة كمركز رئيسي بمعرّفها ووقفها. إغلاق الأصلية بسبب آخر يرقّي المعاكسة أيضًا.
- إذا توقفت المعاكسة وحدها، تبقى الأصلية تحت وقفها ولا تُفتح معاكسة ثانية للأصلية نفسها.
- لا يُسمح بدخول عادي جديد على العملة ما دام أي مركز عليها مفتوحًا، حتى لو بقيت المعاكسة المرقّاة فقط.

نجاح المعاكسة لا يعني أن صافي المركزين معًا أصبح موجبًا. التنفيذ بسعر السوق المرصود، ولا يضمن سعر الوقف نفسه.

## التشغيل داخل Ubuntu في Termux

يتطلب Python3.11+ وGit وvenv:

```bash
cd /root
git clone https://github.com/khaledhasneen1993/Final-4.git
cd Final-4
bash run_paper.sh
```

السكربت يجهّز `.venv` ويثبت المكتبات. ملف الحالة الافتراضي `paper_state_final4.json`، مستقل عن Final-3. Ctrl+C يحفظ المراكز ولا يغلقها؛ تتوقف مراقبتها حتى الاستئناف.

لحساب جديد منفصل:

```bash
bash run_paper.sh --state sessions/final4-new.json
```

## استئناف حساب الانعكاس السابق

ملفات الحساب الموجودة على هاتفك لا تنتقل تلقائيًا بمجرد نقل الكود على GitHub. بعد إيقاف جميع العمليات التي تستخدم الملف السابق، يمكن استئنافه بمساره الصريح، مثل:

```bash
bash run_paper.sh --state /root/Final-3/paper_state_final3_reversal.json
```

هذا المثال مناسب فقط إذا كان الملف هو فعلًا حساب نسخة الانعكاس. يمكن أن يكون حسابك تحت مسار جلسة مختلف؛ استخدم المسار الفعلي المحفوظ لديك. تُؤخذ نسخة احتياطية قبل تحديث هوية إعدادات الحساب إلى Final-4، وتُحفظ المراكز الأصلية والمعاكسة وروابطها والوقف والرصيد والتنفيذات. لا تُحوَّل حسابات نظام الوقف المتدرج إلى انعكاس تلقائيًا. ولا يُعاد الرصيد إلى100 عند الاستئناف.

## اللوحة المحلية والتقارير

```bash
bash run_dashboard.sh
```

تشغّل لوحة هذا المستودع Final وFinal-4 بحسابين مستقلين، على http://127.0.0.1:8787. أوقف أي لوحة أخرى تستخدم المنفذ أولًا. تعرض اتجاهي الأصلية والمعاكسة منفصلين، وتصدر CSV للتنفيذات والصفقات وJSON للحالة. [تفاصيل اللوحة](dashboard/README-AR.md).

## التحقق

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv-dashboard/bin/python -m unittest discover -s dashboard/tests -v
```

تغطي الاختبارات المركزين المتعاكسين والهامش والرسوم وقفل1% وإغلاق الأصلية وحدها عند النجاح واستعادة الحالة السابقة وفصل السجل واللوحة. تعتمد على بيانات وهمية، ولا تثبت نجاح اتصال جهازك بالبورصة أو أداء تداول حقيقيًا.

المحاكاة لا تحسب التصفية أو التمويل أو الانزلاق. تُرفض تيكرات التنفيذ دون توقيت أو خارج ±10ثوانٍ. حافظ النقل على منطق نسخة الانعكاس؛ لم يُطبّق تغييرات مراجعة أخرى على إشارات الدخول أثناء الفصل.
