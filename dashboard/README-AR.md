# لوحة Final وFinal-3 وFinal-4

## تشغيل جديد برصيد100 USDT لكل بوت

أوقف أي لوحة قديمة بواسطة Ctrl+C أولًا، ثم من Ubuntu في Termux:

```bash
cd /root/Final-4
git pull --ff-only
bash run_dashboard.sh --fresh
```

افتح http://127.0.0.1:8787. هذه لوحة محلية للمحاكاة، دون مفاتيح تداول. يثبت المشغّل المتطلبات ويجلب أحدث مصدرَي Final وFinal-3 إلى `.runtime/repos/`، ويستخدم Final-4 الحالي من هذا المستودع. يتوقف إذا كان المنفذ مشغولًا أو مصدر البوت يحتوي تعديلات محلية متتبعة تحتاج حفظها؛ لا يمسحها.

`--fresh` ينشئ مجلد جلسة فريدًا وثلاثة ملفات حالة منفصلة،100 USDT لكل ملف، دون مراكز أو صفقات. يعرض المشغّل المسارات والأرصدة. تبقى ملفات الجلسات القديمة وتقاريرها محفوظة، ولا تُستورد إلى الجلسة الجديدة. عند وجود صفقات جديدة بعد التشغيل، يتغير الرصيد نتيجة الرسوم والنتائج.

## الاستئناف والإيقاف

Ctrl+C يوقف البوتات الثلاثة ويحفظها. لاستئناف الحسابات نفسها:

```bash
bash run_dashboard.sh
```

لا تكرر `--fresh` إلا إذا أردت بداية جديدة. يحفظ `.runtime/dashboard-accounts.json` مسار الجلسة والحسابات. لكل عامل عملية مستقلة واستيرادات مصدره الخاص وأقفال تمنع مشاركته ملف حالة مع نسخة أخرى. تحديث مصدر البوت يتطلب إعادة تشغيله لتحميل الكود الجديد.

يمكن اختيار حسابات سابقة صراحةً عبر `CASCADE_FINAL_STATE` و`CASCADE_FINAL3_STATE` و`CASCADE_FINAL4_STATE` دون `--fresh`. لا تستخدم ملفًا واحدًا لبوتين. تُرقّى حالات Final-3 وFinal-4 المتوافقة عبر أدوات مستودعاتهما مع نسخة احتياطية عند الحاجة. فشل إعداد أي حساب يمنع بدء اللوحة؛ بعض الحسابات قد تكون جُهزت قبل ظهور الخطأ، لكن الجلسة المختارة لا تُستبدل قبل نجاح تجهيز الثلاثة.

## البوتات والإعدادات

| البوت | النظام |
| --- | --- |
| Final | المصدر الأصلي وإعداداته كما هي |
| Final-3 | وقف2.8%، إغلاق40% عند خسارة1.2% ثم50% من المتبقي عند2%، وقفل الربح؛ بعد الجزئي الثاني وقف مرشح0.8% من السعر الحالي دون إبعاد وقف أقرب |
| Final-4 | وقف2.8%، معاكسة45% عند1.8% وإشارة معاكسة، محاولة إغلاق50% من الأصلية ووقف مرشح0.7% من السعر الحالي؛ نجاح المعاكسة عند0.7%؛ مهلة600ثانية بعد إغلاقها؛ حد الخسارة المجمعة معطّل |

تعرض صفحة الإعدادات القيم المحفوظة الفعلية ونسخة المصدر. أسباب الخروج تشمل `SL` و`PROFIT_LOCK` و`REVERSAL_WIN` و`TIGHT_AFTER_REV`، والتخفيف `REVERSAL_HEDGE` في Final-4 و`PARTIAL_1` و`PARTIAL_2` في Final-3. تُجمع رسوم واتجاهات كل مركز حسب معرّفه؛ لا تُخلط الأصلية والمعاكسة.

## استمرار قراءة العملات

كل بوت يحدّث قائمة أعلى40عملة كل600ثانية، ويقرأ تحديثات WebSocket ويقيّم الدخول باستمرار بين تحديثات القائمة. راقب تبويب **حالة البيانات**: عداد الأحداث يجب أن يزيد، وتظهر حداثة كل عملة وحالة الاتصال. تحديث اللوحة كل3ثوانٍ منفصل عن تحديث السوق. انقطاع الشبكة أو بيانات قديمة قد يمنع الدخول، حتى لو كانت واجهة اللوحة مفتوحة. لا يُفتح مركز إلا عند تحقق شروط الحركة والحجم ودفتر الأوامر وباقي قيود البوت.

## كامل التقارير

أزرار **كل التنفيذات CSV** و**كل الصفقات CSV** و**حالة البوتات الثلاثة JSON** تصدّر ملفًا موحدًا مع اسم كل بوت، كما تتوفر ملفات كل بوت منفردًا. التنفيذات تشمل الدخول والتخفيف والخروج النهائي، والصفقات تجمع النتائج والرسوم؛ JSON يتضمن المراكز التي بقيت مفتوحة. بعد الإيقاف تبقى اللوحة متاحة إذا أوقفت البوتات من أزرارها. لإعادة فتح التقارير بعد Ctrl+C دون بدء البوتات:

```bash
bash run_dashboard.sh --no-autostart
```

أزرار الإيقاف تحفظ المراكز ولا تغلقها، وتتوقف مراقبة الوقف حتى الاستئناف. المحاكاة تستثني التصفية والتمويل والانزلاق. اختبارات الواجهة والحسابات تعمل ببيانات وهمية ولا تثبت اتصال جهازك بالبورصة.
